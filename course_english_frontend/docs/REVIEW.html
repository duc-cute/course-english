10. SWOT, rủi ro & anti-pattern

Anti-pattern: “PDF Viewer + bài tập”

Lesson = HTML dài + file đính kèm, không quiz/audio/checkpoint → HS chỉ scroll và đánh dấu xong.

Phòng tránh: block QUIZ bắt buộc; audio checkpoint; rule hoàn thành (ví dụ ≥80% quiz đúng); progress có nghĩa trên server.

Điểm mạnh

  • Block lesson + CMS + reader đã chạy
  • JWT, lớp, enrollment
  • Theme HS/Admin tách

Điểm yếu / rủi ro

  • Chưa quiz/assignment
  • Progress local only
  • Publish chưa filter lớp
  • Scope creep (AI trước quiz cơ bản)

Ví dụ bài “Fruits” (promt.md)

Lesson: Fruits

  2. FLASHCARD         → sourceVocabularySetId
  3. MATCH_IMAGE       → questions[]
  4. SPELLING          → missing letter / type word
  5. LISTEN_CHOOSE     → audio → chọn đáp án

  8. SUMMARY           → key phrases
Một bài tiểu học = Input (content) → Practice (interactive blocks) → Check (quiz) → Reflect (summary).

IMAGE{ "assetId", "caption" }

13.5 Senior EdTech review

Điểm mạnh (đã đúng hướng)

  • lesson_blocks + payload_json = plugin architecture sẵn.
  • Tách LessonAsset — media tái sử dụng nhiều block.
  • Reorder block, publish flow, reader có TOC.

Điểm yếu cần sửa

  • Enum Java 7 loại — chặn thêm FLASHCARD, MATCH_IMAGE không migration.
  • FE switch if blockType — chưa registry, khó scale 30+ block.
  • Không lesson_block_progress — interactive block không có ý nghĩa.
  • Editor chỉ TEXT/IMAGE — taxonomy promt chưa vào UI.

Cải tiến đề xuất (thứ tự)

  1. S0: Mở block_type VARCHAR + document schema từng type (OpenAPI / Zod).
  2. S1: Hoàn thiện CONTENT (AUDIO, VIDEO, PDF) + TEACHING cơ bản.
  3. S2: FE BLOCK_REGISTRY + progress API từng block.
  4. S3+: VOCAB PRACTICE → GRAMMAR PRACTICE → ASSESSMENT → SPEAKING (V3).
  5. S8: Drag-drop Lesson Builder cho giáo viên.

15. Hạ tầng V2 — Redis, RabbitMQ & WebSocket (sau Lesson)

Mục này ghi kế hoạch hạ tầng sau mục 13: tối ưu đọc (Redis), xử lý nền email + notification (RabbitMQ), và chuông realtime (WebSocket). Ba lớp bổ sung nhau, không thay thế. MVP (< 1k HS) vẫn MySQL + CDN; triển khai dần theo 15.6.

Điều kiện tiên quyết: Lesson Player + progress API ổn định; module Notification (S9) có bảng notifications. Tham chiếu scale: 11.3 · checklist notify: 2.8.

15.5 Luồng tích hợp — ví dụ publish lesson

GV POST /lessons/{id}/publish
    │
    ├─► MySQL: status = PUBLISHED
    ├─► Redis: EVICT lesson:detail:{id} + syllabus
    ├─► RabbitMQ: publish lesson.published
    └─► Response 200 (ngay)

RabbitMQ → NotificationWorker
    │
    ├─► Query enrollments (classroom)
    ├─► FOR each student:
    │       INSERT notifications (user_id, type, title, link, read=false)
    │       optional: queue notification.email (1 message / user)
    │       IF online: WebSocket push
    └─► EmailWorker: SMTP (retry 3x → DLQ)

Đọc bài sau publish: HS gọi GET /lessons/{id}/detail → Redis cache (15.2). Notify chạy song song, không chặn đọc bài.
