# course_english_frontend

React + Vite — Admin + Student (Course English).

## Chạy

```bash
copy .env.example .env
npm install
npm run dev
```

`VITE_API_URL` trỏ tới backend (mặc định `http://localhost:7070/api/v1`).

## Build

```bash
npm run build
```

## Tài liệu review

- **[docs/README.md](./docs/README.md)** — danh mục chức năng (tóm tắt)
- **REVIEW.html** — `docs/REVIEW.html` + `public/docs/REVIEW.html` (checklist chi tiết)
- Trong app: `/admin/review-doc` (iframe)
