1. Cấu trúc chung

Một Lesson gồm nhiều LessonBlock, chia 2 tab trên Lesson Player:

Tab Block types (blockTypes.ts)
Bài học (study) TEXT, IMAGE, VIDEO, AUDIO, CALLOUT, SUMMARY, VOCABULARY, SLIDE_DECK
Bài tập (practice) EXERCISE_SET, QUESTION_REF
Shell học viên (đã có): mục lục (TOC), tiến độ đọc %, chuyển tab Bài học ↔ Bài tập, URL slug /student/lessons/{slug}, badge tiến độ trên danh sách bài, practice attempt API.

2. Tab BÀI HỌC — từng loại block

Block Admin (GV) Học viên Ghi chú
TEXT ✅ Rich text ✅ HTML reader —
IMAGE ✅ Upload + caption ✅ Hiển thị ảnh Storage /storage/...
CALLOUT ✅ Editor ✅ CalloutBlock tip / warning / definition
SUMMARY ✅ Editor ✅ SummaryBlock Danh sách ý tóm tắt
VOCABULARY ✅ Gắn bộ từ ✅ List / flashcard Resolve live từ vocabulary_sets; audio UK/US (feature flag)
SLIDE_DECK ✅ Import ZIP PDF ✅ Trình chiếu / Cuộn Canva → PDFBox → PNG; không có trong menu “+ Thêm khối”
VIDEO ❌ ⚠️ Placeholder Có trong enum BE; HS thấy “Phase P1”
AUDIO ❌ ⚠️ Placeholder Có trong enum BE; HS thấy “Phase P1”

SLIDE_DECK — chi tiết

  • Import: ZIP chứa nhiều PDF (mỗi file = 1 slide), tối đa 50MB / 100 PDF
  • Lưu file: {STORAGE}/lessons/{lessonId}/slides/{batchId}/slide-NNN.png
  • Hiển thị: PRESENTATION (prev/next, fullscreen) hoặc SCROLL (ảnh xếp dọc)
  • Migration DB: 015_slide_deck_block_type.sql — block_type → VARCHAR(64)

3. Tab BÀI TẬP — 2 loại khối

3.1 EXERCISE_SET — nhiều câu trong một block

Vai tròĐã có
Admin Form soạn câu (không JSON tay); import CSV/Excel; cài đặt shuffle, % đạt; preview số câu
Học viên ExercisePlayer stepped; shuffle; giải thích từng câu; màn kết quả + xem lại; session localStorage; POST practice attempt khi nộp bài

3.2 QUESTION_REF — trỏ ngân hàng câu

Vai tròĐã có
Admin Picker từ Question Bank (/admin/questions); CRUD + import CSV/Excel bank
Học viên Cùng ExercisePlayer — resolve câu từ bank khi load lesson

4. Trong EXERCISE_SET — 9 dạng câu hỏi

Dạng Mô tả Admin soạn HS làm Sinh từ bộ từ
MULTIPLE_CHOICE Trắc nghiệm 4 đáp án ✅ Form + import ✅ ✅ MCQ
MATCHING Ghép cặp trái–phải ✅ Form ✅ ✅ Matching
LISTEN_CHOOSE Nghe → chọn đáp án ✅ Canvas ✅ ✅
SPELLING Nghĩa VI → gõ từ EN ✅ (chủ yếu gen) ✅ ✅
LISTEN_TYPE Nghe → gõ từ EN ✅ (chủ yếu gen) ✅ ✅
FILL_BLANK Điền từ vào ___ ✅ Form tay ✅ ❌
REORDER_SENTENCE Sắp xếp chip thành câu (3–15 từ) ✅ Form ✅ (tap chip) ❌
TRUE_FALSE Đúng / Sai ⚠️ Player only ✅ ❌
Admin EXERCISE_SET — nút “+ thêm câu” hiện có: MCQ, Matching, Fill blank, Reorder. SPELLING / LISTEN_* thêm qua wizard sinh từ bộ từ hoặc duplicate/import. TRUE_FALSE chạy trên player nhưng chưa có nút thêm trong editor.

5. Luồng GV thường dùng (đã hỗ trợ)

Soạn TEXT / IMAGE / CALLOUT / SUMMARY
  → + Bộ từ vào bài (VOCABULARY + tùy chọn MCQ / MATCHING / LISTEN…)
  → Import slide ZIP (SLIDE_DECK)
  → Khối EXERCISE_SET (form hoặc import CSV) hoặc QUESTION_REF (bank)
  → Publish (LessonPublishValidator)
  → HS: tab Bài học + tab Bài tập

7. Tóm tắt nhanh

Bài học

6/8 block dùng được thật:

TEXT · IMAGE · CALLOUT · SUMMARY · VOCABULARY · SLIDE_DECK

VIDEO / AUDIO: enum có, UI chưa.

Bài tập

2/2 khối block:

EXERCISE_SET · QUESTION_REF

8/9 dạng câu chạy player;

TRUE_FALSE: player có, admin chưa tiện soạn.
